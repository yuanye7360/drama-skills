# 表演弧、动作预算与节奏

## 1. 动作预算不是计数器

动作预算问的是：在 accepted duration 内，演员能否保持故事重点，清楚完成必要动作/反应/对白和 end state？它不是“每镜最多三个动词”或“每秒固定字数”。动作距离、接触复杂度、语言节奏、停顿、表演强度与相机是否需要等待，都比动词数量重要。

**`reviewed_invariant`**：general feasibility 由独立 reviewer 用 shot、motion、对白和时长证据判断。只有显式 segment 数学超时才是 `structural_invariant`。

## 2. 构造可演的动作链

### 先找不可删的 spine

从 shot purpose 反推：

- 哪个动作造成信息/权力/情绪变化？
- 哪个 reaction 让观众读懂变化？
- 哪个动作必须完成才能到 accepted end？
- 哪些只是“让画面忙起来”？

保留 spine，装饰动作最后加入。短镜头常见的有效结构是“一次决断动作 + 一次对方/自身 reaction”，但这只是 **`craft_default`**。

### 给动作以条件与结果

动作 stage 至少明确 actor、方向/对象和到达结果。接触动作注意顺序：先靠近、再触碰、再施力、物体才变化；持物转手必须写清哪只手、何时释放/接住。角色不能在同一时刻用同一只手完成不相容任务。

空间位移要尊重 shot start 的距离和障碍。若要穿过房间、开锁、取物、返回、说完长对白，问题通常不在 prompt 措辞，而在 shot boundary/时长，需要 revision request。

### 给角色一件手上的事

角色很少应该只是「站着说话」。给他一件在本镜合理、持续进行的手边动作——擦拭工具、数钞票、缝补、倒水——让台词压在动作上面说，而不是动作专门停下来为了说话让路。这不是装饰性细节：手上有实事在做，表演才有支点，沉默也有地方落，比空手站立更难显出摆姿势的痕迹。

最强的重音往往不是新增一个表情，而是**让这件手边动作停下来**：他正在擦的杯子停在半空，他正在数的钱不再往下数。这一下停顿本身就是事件，比任何新增动作都更省而更准，也是标记 beat 变化最经济的写法。手边动作在 `ordered_subject_motion` 里作为持续背景交代清楚起点/终点；`performance_arcs[]` 的 `choice` 或 `visible_leak` 引用它的中断即可，不必分别发明两套动作。

手边动作还有第三个作用：**怎么做这件事本身就是潜台词**——同一句「我没事」，配上稳稳数钱和配上数钱数到一半数错，是两种角色，不需要再加一句形容词去解释区别（潜台词的完整讨论见下文「Meisner 五要素」）。

**`craft_default`**：不是每镜都要配一件手边动作，纯对话特写、动作已经很满的镜头可以省略；这条只在角色明显闲置双手、又需要额外支点时使用。

### 同时发生的合理用法

“同时”适合可自然叠加的通道：角色说话时缓慢抬眼，环境雨声持续，camera 平稳跟随。不要用它压缩互为条件的动作，或让双手/身体执行物理冲突。

## 3. 构造可见的表演变化

### Meisner 五要素：目标、障碍、手段、节拍、潜台词

表演的核心公理：**表演是压力下的行为，不是情绪的展示**。角色想要什么、什么挡着他、他用什么方法去争取——情绪是这场争夺的副产品，不是要直接写进提示词的东西。下面五个概念是 `performance_arcs[]` 各字段真正要回答的问题，逐一展开后再对回字段。

**目标（Objective）→ 落在 `agenda`。** 目标是角色在**这一镜、此刻、向着某个具体对象**想要什么，永远是一个瞄准对方的及物动词短语：「让他先松手」「求对方通融一周」「让她相信自己没有在怕」。目标绝不能是一个状态词——「生气」「愧疚」「害怕」都不是目标，状态没法直接演，只能是达成或落空目标之后自然出现的结果。目标背后往往还有一层贯穿全剧的终极目标，本镜的目标只是通向它的一步；`agenda` 只需要写清这一步，不必每次都倒推到终极目标。判断方法：把 `agenda` 的内容读出来，如果读出来的是一个形容词或情绪状态，说明还没写到目标；改成一个瞄准某人的动词短语才算到位。

**障碍（Obstacle）→ 落在 `receive` 与场景既有条件。** 障碍是挡在目标前面的东西，分两种：**外部障碍**（另一个角色想要相反的东西、房间里有旁观者、还有两小时就要交货）和**内部障碍**（自尊不允许他开口求人、他自己都不信自己刚说的话）。障碍决定了这一镜有没有戏剧张力——问「如果这一步没达成会怎样」，答案必须让角色感到害怕或代价高昂，否则障碍不成立，目标也不值得追。`receive` 记录的正是障碍在这一刻具体撞上了角色什么：一句反驳、一个新证据、一次沉默。没有可指认的障碍，`receive` 就只是走个过场，不构成表演。

**手段（Tactics）→ 落在 `choice`，且必须随受阻变化。** 手段是角色**当下**争取目标的具体方法，永远是动作动词：施压、讨好、羞辱、哀求、挑逗、讨价还价、拖延。手段会随场景变化——活人在一种手段失效后会换一种；一整段戏只用一种手段（从头哀求到尾，或从头施压到尾），是死戏最常见的成因。`choice` 不必是新动词，但必须能答出「这一步和上一步比，手段真的换了吗」：压低声音换成提高声音、退让换成逼近，是换手段；同一个动作只是形容词升级（「更愤怒地说」），不是换手段。若一整条 `performance_arcs` 里 `choice` 从头到尾只有一种手段，先判断是该在这里断句换一条 arc，还是这一镜本就只承载一次不变的坚持——后者同样合法，但要能说出原因，不能是没想过。

**节拍（Beats）→ 手段变化落在 `timing_plan` 分段上的可见标记。** 节拍是最小的行为单位：角色想要一件事、用一种方法追求它的这一段时间。一个节拍在以下任一情况发生时结束：目标达成、手段失败、新信息进入、力量对比改变。**节拍转换必须在行为上可见**——一次停顿、一次坐姿/重心改变、一次语速改变、一次视线转移，缺一不可；没有可见标记的所谓"转换"，观众读到的仍是同一段。手段（`choice`）换了，通常就意味着一次节拍转换，两者经常是同一件事的两种记法：`choice` 回答"手段变了没有"，节拍标记回答"这次变化在画面上长什么样"。一个完整的短镜多为 1-2 次可见节拍转换；若同一镜需要 2-4 次转换才能讲完这段戏，通常说明动作量已经超出单镜时长（见「5. 超载修订与审查」的超载判断），该考虑拆镜而不是硬塞。

**潜台词（Subtext）→ 落在 `mask` 与 `visible_leak`，不能被直接演出来。** 潜台词是角色真正在想、真正想要的东西，跟他嘴上说的不是一回事。潜台词的性质决定了它**不能被表演**——它只能在角色说着假话、追求着真目标时自己渗出来。可以植入的渗出信号：明明是问句却不是真的在问（心里已经有答案）；反复问同一件事（不相信刚才的答案）；话题被生硬地转开（回避某个真相的护盾）；不合时宜的笑（对脆弱的防御）；答案短得反常（「没事。」「行。」——一扇关上的门）。`mask` 只在角色确实在掩饰、维持、压住什么时才写，写清他在压什么；`visible_leak` 写这份掩饰漏出来的具体信号（目光、尾音、手部、距离、物件动作），且必须是当前景别读得到的。若角色的话和他真正的目标一致，就不存在潜台词，`mask`/`visible_leak` 该删除，不要为了字段齐全编一个掩饰。

**对回字段速查**：`agenda` = 目标，`receive` = 障碍撞上角色的那一刻，`choice` = 手段（是否换了），节拍转换 = `choice` 变化在 `timing_plan` 分段上的落点，`mask`/`visible_leak` = 潜台词的渗出，`landing` = 这一轮追求（无论达成或落空）落到的 accepted end 状态。

**`craft_default`**：以上是理论框架和自检问题，不是新增的必填结构；能不能用五要素的语言讲清楚这一镜在演什么，是判断 `performance_arcs` 写得够不够格的最快方法，答不出某个问题时先确认这镜是否真的需要对应字段，而不是硬凑答案。

**`reviewed_invariant`**：五要素的具体取值（目标是什么、障碍是什么）必须与剧本 agenda/shot purpose 相容，不能凭这套理论自行发明新的角色意图或关系。

### Listening and reaction：听与反应的四个可观察标记

表演的质量更多体现在台词之间，而不是台词本身；一个角色有没有「活在」场景里，最容易从他怎么「听」看出来。四个可写进 `receive`/`visible_leak` 的具体标记：

1. **反应先于对方话说完**：角色在对方话说到一半时就已经理解了要点——脸和身体已经开始给出回应。等对方一句话说完才「切换表情」是死戏最典型的样子。`receive` 应该写清反应在对方台词/动作**尚未结束**时就已经开始，而不是描述「听完之后」。
2. **想在先，话在后**：面对一个难以回答的问题，角色在开口前有一个微小的停顿——观众能看到他在决定要说什么。用统一速度、毫不迟疑地立刻给出答案，读起来像背好的台词，没有生命。这个停顿可以写进节拍转换或 `timing_plan` 的分段留白，不必单独造一个字段。
3. **消化的瞬间**：遇到重要信息（消息、威胁、羞辱）时，角色需要时间去消化它——可能只是零点几秒，也可能是一段长停顿。这正是近景存在的理由：一张脸、一个失焦的目光，世界在晃。`visible_leak` 可以直接写这个消化瞬间的具体样子（目光短暂失焦、呼吸一顿），比直接跳到「她生气了」更可信。
4. **被对方带动**：语速、音量和能量应该随对方变化——被吼了之后，用反吼或用刻意的安静去回应，但一定是「回应」，不是「没听见继续说自己的」。这条也是 [camera-audio-continuity.md](camera-audio-continuity.md) 音量对比规则（越重要的话越轻）在「听」这一侧的对应：对方升高音量时，角色的选择本身（跟着升高，还是刻意压低）就是一次 `choice`。

**`reviewed_invariant`**：这四条标记描述的是「听起来/看起来是否在真实互动」，审查者据此判断 `receive`/`visible_leak` 是否只是摆设的情绪标签；具体取值仍需与剧本触发相容。

### 身体的物理生活：四个参数

身体在第一句台词说出来之前就已经在讲故事。给每个承担表演变化的角色，在 `performance_arcs`/`ordered_subject_motion` 里想清楚这四个参数当下的取值，而不是只写「她很紧张」：

- **重心**：高（挺胸、抬头——自信、攻击性、地位）还是低（垂肩、佝偻——疲惫、恐惧、屈从）。
- **节奏**：快而毛躁（紧张、兴奋剂式的能量）还是慢而经济（掌控、威胁——最危险的人往往动得最少）。
- **开放度**：肩线打开、掌心可见，还是抱臂、低头、身体蜷起。
- **呼吸**：又高又急（恐慌）还是又低又慢（掌控）。呼吸是状态最诚实的指标——声音和物理状态必须匹配：一个刚跑完的角色不可能用平稳的声音说话。

这四个参数默认应该保持稳定，只有明确的触发才改变其中一项或多项；改变的方向和幅度就是这一镜真正的表演内容，比任何情绪形容词都具体。它们和下文「角色不是情绪滑块」里的目光/呼吸/身体/语言/决断动作五个外显通道是同一套东西的两种切法：那五个是「写什么会动」，这四个是「当前的物理基线在哪」，两者合起来才知道「这一次的变化算不算变化」。

**`craft_default`**：不要求每次都四个参数逐一写出；只写这一镜真正参与变化、且当前景别读得到的那一到两个。

### Status：看不见的等级

地位是角色**做什么**，不是他**是谁**——一个保洁员可以在某个瞬间地位比在场的老板更高。

高地位的身体信号：头部不动、动作缓慢、长时间的注视、回答前的停顿、占据空间、随手碰别人的东西。低地位的身体信号：手忙脚乱、频繁自我触碰（脸、头发）、破碎的语言、讨好性的笑、用眼神请求许可。

表演里最有戏剧性的往往是**地位的破裂**：一直强势的上级突然露出一秒钟的害怕；一直讨好的下属忽然停止微笑。一个有力的场景形状是「高开低走」或「低开翻盘」——角色以一种地位进场，在场景中途翻转。这条不要求每镜都写地位翻转，只是在需要制造这类转折时，可以直接把「地位破裂」当成节拍转换的触发写进 `choice`/`visible_leak`：翻转本身就是一次可见的、值得单独成为一拍的事件。

**`craft_default`**：地位是一层可选的解读工具，不是每个角色都需要显式标注；多人镜里最有用的场景是「谁的地位在这一镜里变了」，只写真正变化的那一位。

### 角色不是情绪滑块

不要机械排列“平静 30% → 紧张 70% → 震惊 100%”。从角色 agenda 和触发选择外显通道：

- 目光：寻找、回避、锁定、短暂失焦；
- 呼吸/声音：吸气被截断、语速变化、音量反常降低；
- 身体：重心撤后、肩线防御、手指停止或反复动作；
- 语言：停顿、吞字、改称呼、打断或刻意完整地说完；
- 决断动作：收回手、让路、把物件推回、关门。

选择能被当前景别读到的信号。远景不应依赖细微眼睑变化；近景不必用夸张全身后退替代内心处理。

### 目光与眨眼：最容易穿帮的通道

长时间锁定不动、不眨眼，或眨眼节奏和角色状态脱节，是表演读起来假的常见原因，比构图或动作错误更容易被看穿。给目光信号补上具体标准，而不是只写「看向某处」：

- **眼神先于头转**：目光先移到目标，头才跟着转过去，不要头眼同时甩动；这个先后本身就是一个可写的动作阶段。
- **扫视不是冻结**：即使角色处于克制或高地位状态，目光也该有细微扫视（在对话对象、手部、出口之间移动）；完全一动不动只在「刻意维持的静止」这一种状态下才成立，且要写清这是角色的选择，不是没写目光。
- **眨眼节奏挂在状态上，不是随机**：压力下眨得快而碎，掌控/沉稳下眨得慢而深；出现解离或恍惚感时可以写一次眨眼后视线发虚。眨眼节奏的变化本身可以作为 `visible_leak` 的具体内容，不必再另造一个信号。
- **有反光的眼睛才算活**：近景里补一句「眼睛湿润有光」一类可见描述，避免只剩「盯着」「看着」这类不含反光/湿度信息的干描述。
- **克制的静止是选择，不是死掉**：若角色的表演基调本身就是几乎不眨眼的镇定（例如高地位、极度自控的人物），眨眼仍要写得稀疏、缓慢、带决断感，视线仍要缓慢地随注意力移动——这是一个被写出来的选择，不是省略了目光描述；两者在文字上的区别就是「稀疏而缓慢」和「完全没写」。

**`craft_default`**：以上五条只在近景/中近景等眼神真正读得到的景别里写；远景不必依赖细微眨眼，改用视线转移或身体朝向替代（呼应上一段「选择能被当前景别读到的信号」）。

### 可选：表演标尺只用来校准形容词

只有创作者已经声明并接受一套表演标尺时才使用它。**本文档不提议任何刻度、增量公式或
每镜升压规则**；没有创作者标尺时就写可见表演，不写数字。

标尺唯一的职责是**消歧一个形容词要演到多硬**。“淡然”“不安”“恐惧”之间有清楚的高低
次序，而同一个词在不同人物、不同场合的合理落点其实相当集中——所以标尺回答的是“这里
的‘不安’是欲言又止，还是手抖到握不住杯子”，不是“这一镜该比上一镜更用力”。这也是
[production-prompt-grammar.md](production-prompt-grammar.md) 里“哪些情绪形容词可删”的
另一面：能被标尺定住落点的形容词才值得留下，定不住的应当换成可见动作。

用法：

- **取值来自形容词本身**，由人物、触发和后果决定落点；不从镜号、段序或“第几次升级”
  推导。同一个词在本集第 3 镜和第 30 镜可以是同一个落点。
- **保持与变化同样合法，而且保持更常见**。相邻段之间不变是最常出现的正确选择：一个
  角色可以在整场戏里维持同一强度，变化发生在别人身上或发生在信息上。为了“有层次”
  每段都动一格，是把标尺当节拍器用。
- **按最小可见增量变化**。相邻段之间的改变小到刚好能被当前景别看见即可；跨段一次跳
  多级必须有段内可指认的触发（一句台词、一次接触、一个揭示），否则观众看到的是换了
  个人，而不是同一个人变了。
- **只标注本段真正参与变化的角色**。旁观者、画外角色和状态未变的人不进标注；为“字段
  齐全”给全场人各标一个值，会让审查者分不清哪一处变化是有意的。
- **数字不替代表演**。标尺值旁边必须仍有可见通道（目光、呼吸、身体、语言、决断动作）；
  只有数字的表演等于没写表演。

与剧本的关系：剧本的 `（情绪）` 括注是表演状态和说话方式的同一个来源。标尺值、可见
表演与台词的说话方式都应当从这一个括注派生；三者互相矛盾时以剧本括注为准，需要改动
就发修订请求，不在提示词里自行折中。

### 单人或多人 `performance_arcs[]`

每个真正承担本镜可见变化的角色才写一条；状态未变的旁观者不因字段完整度进入主表演通道。
以下是可选词汇，不是六项必填拍表：

1. **agenda**：他此刻想维持或取得什么；
2. **receive**：准确触发怎样被角色接收；
3. **mask**：角色确实在掩饰、继续或压住什么时才写；
4. **visible_leak**：掩饰漏出的目光、尾音、手部、距离或物件动作，且当前景别读得到；
5. **choice**：说、做或刻意不做一个有方向的选择；
6. **landing**：选择落在 accepted end 状态。

五要素与这六个字段的完整对照见上文「Meisner 五要素」一节；最短的落点是 `agenda` = 目标、`receive` = 障碍撞上的瞬间、`choice` = 手段（是否换了）、`mask`/`visible_leak` = 潜台词的渗出、`landing` = 落到的 accepted end。

需要时从 [`performance.fragment.json`](../assets/performance.fragment.json) 复制统一结构；
`actor_ref`、触发和注意交接对象都使用准确 `ArtifactRef`，不写裸角色名或另造引用形状。
只保留能让本镜更可演、更可读的字段。例如角色认出桌上印章后仍试图把原句说完，尾音降低、
右手离桌，最后停止阻拦并让出通道；若没有掩饰，就删除 `mask` / `visible_leak`，不要填 `none`。

若本镜只需要“听见门响后停止翻页”，写触发和可见动作即可，不必把其余字段补成同义句。

空镜、道具细节、纯空间转场、无人物镜头，或只有物理动作而没有可见内在处理的镜头，省略
`performance_arcs[]`。单人镜也不因人数自动生成 arc；多人镜更不是给每个人复制同一“震惊”。不同人物可以早认出但继续说、
晚半拍才让路、故意制造噪声掩饰，或看见别人停顿后才理解变化。所有差异都要来自角色立场、
已接受信息和空间关系。

只在注意真正交接时，用 `attention_handoffs[]` 简写“谁/什么拥有注意 → 哪个可见或可听触发 →
注意转给谁/什么”；没有交接时省略该字段。
交接两端可以是角色、道具、证据、声源或已建立的空间区域；分别指向拥有该事实的准确
ArtifactRef，不要为了套片段把道具或空间伪装成 `CHAR-*`。
交接不是全员同步转头：例如说话者尾音降低 → 最近的听者先停手 → 群体让路 → 主角获得空间。
每一跳说明为何当前景别、遮挡和声音能读到；细微眼神在远景不可读时，改成视线转移加手部停顿，
而不是只增加情绪形容词。

- **`craft_default`**：若一镜只有信息接收，宁可把变化做小而清楚，不必每镜“情绪大爆发”。
- **`reviewed_invariant`**：表演选择应与剧本 agenda/shot purpose 相容，不能凭 prompt 改写人物立场。
- **`taste_option`**：停顿多寡、微表演或类型化表演由导演风格决定。

### Ensemble 与空间中的动机

多人同镜时，观众的注意力和角色的空间移动都遵循几条经验规律，能帮助 `attention_handoffs[]` 和多角色 `performance_arcs[]` 写得更可信：

- **群体反应像波浪，不会同步**：一个人先听懂，第二个人慢半拍，第三个人可能完全没反应过来。所有人同时做出一致反应，读起来是假的（除非刻意设计的整齐喜剧节拍本身就是笑点）。`attention_handoffs[]` 的每一跳都应该写清楚谁先、谁后、谁完全没跟上，这正是 `VID-16`（多角色表演要区分承担变化的人，不强制给全场同一个情绪）在时间维度上的展开。
- **反应比动作本身更值钱**：一件事发生后，最有信息量的画面往往不是事件本身，而是「看到这件事的人的脸」。多人镜若时间/景别有限，优先把注意力给反应者而不是事件制造者。
- **在关键威胁点，喧闹忽然冻结**：群演持续的细碎动作（挪重心、手势、倾身）到了真正的威胁瞬间会全部停下——从「闹」到「静」的反差本身就是一种标点，比继续加动作更有力。
- **移动 = 动机**：没有人会毫无理由地穿过一个房间。几种被验证过的移动含义可以直接借用：靠近（升级）、转身背对（拒绝或藏起表情）、对方坐着自己却站起来（争夺地位）、冲突中途坐下（反常的掌控）、在门口停住（决定的临界点）、开始收拾东西（用身体宣布最后通牒）。把这些当作 `choice` 的候选词汇，而不是「她走向他」这类没有理由的移动。
- **强者静而弱者动，威胁不需要前戏**：危险感通常不是靠「危险的那个人」演出来的，而是靠周围所有人的紧张撑出来的；真实世界里的暴力往往没有预兆——没有意味深长的停顿，没有慢镜头式的转身。若剧本要求突发的冲突，`ordered_subject_motion` 不必给它加一段「蓄力」动作。
- **磨损会累积**：如果角色在整条故事线里被逐渐消耗，这份消耗要在身体上累积（更灰、更重、反应更慢），不能在每一镜之间重置——这与 [motion-recipe.md](motion-recipe.md) 3.7 节「结束报告」的状态延续性是同一个原则在更长时间尺度上的应用：短程是「这一镜刚发生的事不会瞬间归零」，长程是「这几集累积的消耗不会莫名其妙恢复」。

**`craft_default`**：以上是构造多人场面时的经验规律，不是新增字段；能不能落地仍取决于当前景别、遮挡和 `attention_handoffs[]` 实际能否读到这些差异。

**`reviewed_invariant`**：谁先反应、谁地位更高、谁的移动动机是什么，必须能从角色立场、已接受信息和空间关系推出来，不能凭这套理论自行发明新的关系或知识。

### 反应的对象

明确角色对什么反应，而不是孤立写“她突然震惊”。触发必须来自 accepted shot/script/audio，或是 already-visible 环境事实。Reaction 若揭示新知识，要确认角色在这一刻确实获得它。

## 4. 时间与对白共同预算

### 相对时间优先

在不需要精确秒段时，用“开头保留一拍”“话音落下后”“动作完成前”“结尾停留”表达节奏。这样保留演员和剪辑弹性。

### 显式时间

需要 timing 时，列阶段与 overlap：

```text
0.0–0.8s：保持 start，听见门闩声后目光转向门
0.8–2.6s：左手压住册页，身体慢慢前倾（对白从 1.1s 开始，与动作重叠）
2.6–4.0s：说完后停住，右手仍握笔，落到 accepted end
```

区间不可无意重叠；显式非重叠总量/最大终点不得超 duration。总量小于 duration 时也要处理：把余量分配给已有阶段或补一个有内容的收尾段，未分配的秒数会被执行端用自选动作填满（见 [motion-recipe.md](motion-recipe.md) 3.6）。不要为了塞进数学窗口而静默删掉 exact dialogue。

### 对白预算

评估：句长与语言、人物语速、情绪造成的停顿/吞吐、是否需要听见对方/环境 cue、口型要求、动作是否能与说话叠加、结尾是否有 reaction landing。固定每秒字数只能作为 production profile 的可覆盖估算，不能成为通用规则。

对白太长时选项：

1. 简化非必要动作，让对白成为主事件；
2. 若 script 允许，把动作与对白合理重叠；
3. 请求 storyboard 延长/拆镜；
4. 若要改台词，请求 write owner。

Video-prompts 不能自行删字、改词或把对白变 VO。

## 5. 超载修订与审查

### 超载征兆

- 一个角色完成多次远距离往返和复杂物件操作；
- 多个角色都有独立大动作，但 shot purpose 只需要一次揭示；
- 长对白、强情绪转折、精细手部动作和复杂 camera move 争夺同一几秒；
- 结尾没有时间落住，end state 只被一句“最后到达”宣告；
- 为了赶时长，动作顺序违反接触因果或表演没有接收过程。

### 修订优先级

1. 删除无故事功能的环境/手势活动；
2. 合并可自然连续的动作，保留因果节点；
3. 选择一个主要注意中心，其他角色用必要 reaction；
4. 保留对白与 accepted end；
5. 仍超载则发 storyboard revision request（split/extend/reblock），不越权执行。

### Reviewer 证据格式

```text
Evidence：SHOT duration 4s；dialogue ref DLG-... 为完整两句；motion 要求角色从窗边走到门、开三道锁、回身交物，并保留结尾反应。
Impact：关键交物和反应难以清楚落地，accepted end 可能只被宣告而未实现。
Required fix：删掉非必要回身动作，或请求 storyboard 拆为两个 authored shots；不得删对白。
Classification：reviewed_invariant
Owner：video-prompts（精简）/ storyboard（改边界）
```

不要只写“动作太多”。也不要因 prompt 有四个动词就自动报错。

## 6. 角色一致性：Master Profile 与逐镜改写

这一节讲的是一套写法方法，不是本技能的产物。角色的外观与声音身份锚点属于制作形态/资产档案（Character、Look、`voice_direction`），本技能对它们只读；下面这套"角色行为如何跨镜保持一致"的方法，套件内目前没有其他文件承担，因此完整写在这里，供撰写 `performance_arcs` 时参考——即便项目还没有一份正式的角色行为档案，这套方法也能帮助判断"这个角色这一镜该有的样子，和上一镜是不是同一个人"。

### Master Profile 写什么

每个反复出场的角色理想情况下有一份**行为身份档案**——不是外观，是"这个人物怎么动、怎么说话、下意识会做什么"的永久说明。典型长度是一段 150–220 字的连续叙述，不用条列，包含以下固定内容（不规定具体格式，只规定要回答什么）：

- **体态即传记**：年龄、体格、姿态怎样透露这个人的经历——"常年紧绷的肩膀""过度挺直以显示权威的站姿"。身体是一份文件，职业、旧伤和自我形象都要能从体态里读出来。
- **心理引擎一句话**：一个从性格/背景直接解释体态和行为的驱动力（"几十年的等待——等客人、等回合、等麻烦——让耐心成了他的武器"）。
- **声音的戏剧行为**：不是声音本身（那是 `voice_direction` 的事），而是声音**怎样随情境变化**——语速在什么情况下变快、音域在什么情况下下沉、什么时候会破音。**声音身份本身锁定，不随镜调整**：若角色已有 `voice_direction`，那是它的永久声音身份，逐字/原样绑定使用，不因情节改写；这里讲的"戏剧行为"是声音会怎样变化的规律，`voice_direction` 锁定的是声音不变的部分，两者一起使用，互不覆盖。
- **习惯性小动作，每个都配一个触发**：不是"他会转笔"，是"他在琢磨怎么开口撒谎时会转笔"。格式是【小动作】+【触发条件】。没有触发的小动作只是装饰，配了触发才是能被演的信息。
- **步态有名字**：给这个人的走路方式起一个具体的名字（"炮弹式的直冲步""孔雀踱步""老拳手式的滚动步"），再展开重量、步幅、上半身和手的状态、头的角度。命名本身帮助在不同镜头里复用同一个生物力学细节，不用每次重新描述。
- **面具与裂缝**：档案里最有戏剧性的一句，永远是一个"但是，当 X 发生时……"的转折句——常年的强势在被拒绝时突然垮成孩子气的蜷缩；一直大声的人一提到家人脸上就闪过慌乱；严厉的纪律在见到某一个具体的人时融化成笑容。**每份档案至少要有一句这样的转折**，这是角色显得是"一个人"而不是"一个人设"的关键。
- **一个软化对象**：给这张脸恰好一个（不是两个）会让它真正放软的对象——一个人、一只动物或一件东西。只给一个，是为了不稀释角色的主线。
- **不写衣着，不写摄影/调色**：这份档案只讲行为、声音和身体，换任何衣服都该成立；镜头、构图、光线属于每一镜自己的字段，不属于这份档案。

### 逐镜改写，不是照抄

进入具体一镜时，Master Profile **要被重写，不是被粘贴**。这正是 `performance_arcs[]` 要做的事：

1. **只写在场的人**：这一镜没出现的角色不需要重写他的档案。
2. **恒定核心保持不动**：身份、习惯性小动作和情绪主线在每一镜都必须一致，这是角色在多镜之间保持"是同一个人"的关键，不能与档案矛盾。
3. **按本镜重新表达**：从档案里挑选、强调、修改或省略某些行为，去匹配这一镜的姿态（坐/站/跑/躺）、动作、节拍和时间。
4. **转换，不要删除**：一个体态上不可能在这一镜发生的习惯要被**转换**而不是直接消失——一个总在房间里走来走去的角色瘫坐在沙发上时，同一份不安的能量要转移到别处：不停的小幅晃动、手指抠纸、腿的抖动。能量不变，出口变了。
5. **一段连续散文**：改写后仍是这个角色语域下的一段连贯描述，不是条列、不是"档位"标注。
6. **若项目用资产引用，把角色引用带在最前面**：帮助模型把表演绑定到正确的人。

### 合成示例：从档案到本镜

以下人物、场景与台词均为虚构合成材料。

**Master Profile（角色"陈叔"）**：陈叔六十出头，退役码头工人，体格厚重、肩背早已佝偻，一双手布满老茧；坐下和站起时重心都极低，落地极稳。几十年扛货的耐性让他学会了"先不说话"这件事——沉默是他的武器，不是弱点。声音低哑、语速慢而经济，遇到真正棘手的事反而会更轻更慢，从不提速。习惯性小动作：在权衡一件事该不该管时，会用拇指反复摩挲手心一道旧疤；真正下定决心不再退让时，那只手会先攥成拳、停在半空，再放下。走路是一种"码头式的沉步"，脚跟先落地，双肩几乎不晃，像扛着看不见的货。但是，当有人在他面前欺负比自己弱小的人时，那副疲惫的迟缓会在一瞬间消失——脊背绷直，下颚绷紧，旧日扛货的肌肉记忆重新接管身体，而后他往往又强迫自己松开拳头，像是提醒自己已经退休。他的脸只对巷口那只瘸腿的野猫会真正放软。

**逐镜改写（同一角色，坐在自家门口的小马扎上，看着邻居家孩子被人推倒在地）**：陈叔坐在门口的小马扎上，双手原本搭在膝头，重心极低，像随时能不费力地站起。孩子摔倒的闷响传来的瞬间，他摩挲旧疤的拇指停住，视线先移过去，身体却没有立刻起身——这一拍的静止里，几十年"先不说话"的耐性和眼前的事在角力。当推人的那个转过身、还想再伸手时，陈叔的疲惫在半秒内褪尽：后背无声挺直，搭在膝头的手先攥成拳、停在半空，脚跟已经踩实地面。他终究没有起身，只是用那句压得极低、比平时更轻更慢的"够了"截住了对方的手——声音一压低，四周反而静了下来。说完这一句，攥起的拳头才慢慢松开，重新落回膝头，他的重心也重新沉回马扎，只是那道旧疤又被拇指按住，摩挲得比刚才更慢。

**发生了什么**：步态因为坐姿而不必出现，它的能量转移到了重心和"随时能站起"的潜在姿态里；招牌小动作（摩挲旧疤）保留了触发（权衡该不该管），停顿的拳头保留了触发（真正下定决心）；面具与裂缝的转折句在这一镜里被完整兑现——疲惫褪去、肌肉记忆接管、又被自己按下去；音量对比规则（见 [camera-audio-continuity.md](camera-audio-continuity.md)）在这里直接体现为"够了"两个字压得比平时更轻，而不是喊出来；这一镜结束时的状态（拳头松开、重心沉回、拇指按住旧疤）不是瞬间归零，而是刚发生的克制在身体上留下的余势，足够被 `end_report` 承接、被下一镜的 `start_anchor` 继承（呼应 [motion-recipe.md](motion-recipe.md) 3.7 节）。

**`craft_default`**：项目若已经有正式的角色行为档案（不论叫什么名字、存在哪个文件），逐镜改写时以它为准，不要用这份合成范例覆盖已接受的角色设定；没有正式档案时，这套方法可以帮助在多镜之间保持角色行为一致，但不建立新的权威档案——一致性判断仍以剧本 agenda 和已接受的角色事实为准。
