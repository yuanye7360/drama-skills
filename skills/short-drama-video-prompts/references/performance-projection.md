## 本文负责的做法

- `VID-26` — 逐镜表演从已接受的表演主档案投影：保留恒定核心、按本镜实际条件重新
  表达、**转化而不删除**；不整段复制主档案，也不发明档案与剧本都没有的行为。
- `VID-27` — 有表演变化的镜头写清眼神随节拍的变化（眨眼频率、视线稳定度、
  眼中高光）；群戏反应成波不同步。

表演主档案是 `$short-drama-assets` 拥有的跨集资产（`设定集/performance-profiles.jsonl`）。
本阶段按已接受记录只读投影，不修改；档案缺段落时发修订请求给该 owner。
本镜的表演**变化**结构（触发、接收、掩饰、选择、落点）见
[performance-action-timing.md](performance-action-timing.md)；本文只负责"主档案怎么
落到这一镜"。

## 1. 改写，不是粘贴

主档案回答"这个人一贯怎么动"，逐镜投影回答"在这几秒里，这具身体做了什么"。
整段粘贴主档案的后果很具体：跨集的行为清单被塞进一个镜头，执行端读到的是一个人
同时在做五件事，于是它一件也做不好。

关键帧投影的是**一个瞬间**，本阶段投影的是**一段变化**：从起点姿态出发，经过一次
可见的处理，落到分镜负责的终点。

## 2. 四条投影规则（`VID-26`）

1. **只为真的在画面里的角色写。** 不在这一镜里就没有这一段。
2. **恒定核心不变**：身份、声音侧写、招牌小动作、眼神生命、情绪贯穿线。这是跨镜
   一致性的唯一来源，任何一镜都不得与主档案矛盾。
3. **转化，不删除。** 这一镜物理上做不出来的行为要换出口，不是拿掉：一个瘫在沙发里
   的踱步者，同样的神经质引擎位移成不安的微晃、弹手腕、撕纸。**能量恒定，出口改变。**
4. **一段流畅散文**，用这个角色的语域写。不要条列、不要标题、不要"情绪刻度"那种行。

小动作出不出现，看它在主档案里的**触发条件**在这一镜成不成立。没有触发条件的小动作
要么每镜抽搐，要么整片消失。

另外三条来自表演本身、在生成端特别值钱：

- **反应比动作值钱。** 任何事件之后，最有价值的一帧是看见它的那张脸。
- **强者静而轻，弱者忙而吵。** 危险由周围所有人的紧张演出来，不由危险的人演出来。
  威胁没有预告：不要意味深长的停顿、不要慢动作转身。
- **镜头越紧，动作越少。** 特写上只留眼睛与想法；在特写里写活跃的面部表演，
  得到的是抽搐。

## 3. 眼神随节拍变化（`VID-27`）

关键帧锁住的是一个瞬间的眼神；本阶段要写它**怎么变**：

- **眨眼频率**：压力上升时的连续快眨、控制中的缓慢闭合、失神时的一次眨眼加放空；
- **视线稳定度**：锁住不动、来回扫视、在某个细节上停住再回来；
- **眼中高光的温度**：随光位与情绪改变；
- **眼睛领先于想法**：视线比头先到目标。"他刚注意到"写成"头还朝着门，视线已经
  到了信封上"。

节拍一变，这三项就变。整镜眼神不变的镜头，只在刻意的静止（近乎不眨眼的平静）时
成立，而且那时要写明**眨眼是罕见、缓慢、是决定不是冻结**。

## 4. 群戏：反应成波（`VID-27`）

- **反应成波不同步**：一个人先懂，第二个晚半拍，第三个根本没懂。整齐划一＝假，
  除非刻意编排的同步就是这一镜的笑点本身。
- **威胁时全体冻住**：群体持续的细碎动作在关键威胁处全部停。热闹 → 静止的对比
  本身就是标点。
- **只区分真的承担变化的人**（`VID-16`）：不为在场的每个人都写一条表演弧，也不把
  同一种情绪复制给全体。

## 5. 状态不是过程

生成端拍得出"已经在做"，拍不出"开始做"：

    ✓ mid-throw，手臂已伸展 ／ mid-pace，重心已经在前脚 ／ 争执进行中
    ✗ 伸手进包、掏出、抡起

需要一连串变化时，把它写成**逐节拍的状态链**（每个时间块一个已经成立的状态），
而不是一句连续过程。时间块的算术见 SKILL 工作流第 3 步与 `VID-04`。

## 6. 声音身份：说话时逐字复用

角色在本镜说话时，把主档案附带的**声音 prompt 逐字**放进交付文本的声音字段，
不随场景改写（`AST-11`）。角色出场但不说话时，不出现这条。

场景层的气息、音量、停顿与当下情绪写在本阶段的声音字段里，**不回写进声音 prompt**，
也不覆盖它的持续音色锚点，见 [camera-audio-continuity.md](camera-audio-continuity.md)。

只有引号内的台词会被说出来：没有加词、没有即兴、没有字幕、没有旁白（除非要求）、
没有画外声（除非明确指定）、不说出角色名（除非台词里本来就有）。不说话时嘴唇静止。

只为情绪延续需要的前一句，写成"仅前置声音语境，不是画面内容"，且不要把其中的人名、
人物或物件视觉化——除非他们在这一镜里是活跃的。

## 7. 失败征兆与检查

### 失败征兆

- 主档案被整段粘贴进逐镜文本；
- 本镜做不出来的小动作被直接删掉，角色变成一个没有习惯的人；
- 全镜眼神不变，或写成"眼神复杂"这类不可执行的描述；
- 群戏所有人同时做同一个反应；
- 表演写成过程（伸手→掏出→抡起）而不是状态；
- 特写里堆满面部表演；
- 声音 prompt 被按场景改写，或场景情绪被塞进声音 prompt；
- 为不在画面里的角色写了表演段落。

### 检查

1. **结构**：只有在画面里的角色有投影；绑定的主档案记录可解析；说话角色的声音
   prompt 逐字一致。
2. **内容**：独立审查者能否从主档案＋本镜边界推出这段表演？推不出来说明档案缺段落
   （发修订请求）或本镜发明了行为（本阶段修正）。
3. **默认**：投影的详略、语域与节奏是 `taste_option`；眼神与群戏的写法是
   `craft_default`，创作者说明理由即可覆盖。
