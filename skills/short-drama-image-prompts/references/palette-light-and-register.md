## 本文负责的做法

- `IMG-13` — 调色、光线、材质与暂存器都从已接受的视觉方向推导，不在本阶段另发明
  一套；比例与色名要能指回创作者指示、场景内容或参考图。
- `IMG-14` — 审美词只有落成可观察选择（构图、材质、色彩关系、光向、景深）才有信息量；
  技术性描述优先于气氛形容词，但不得用词表或形容词比例阻断交付。

## 1. 这一层解决什么

同一个项目里，人物板、地点板与道具板各自好看、放在一起却不像同一部片——原因几乎
总是同一个：**每张图各自发挥了色彩、光线与质感**。身份锚点解决"是不是同一个人"，
这一层解决"是不是同一部片"。

判断一条视觉描述有没有内容，只需要问一句：**把它删掉，这条 prompt 会不会一字不变？**
会，那它就只是标签，重写。

## 2. 60/30/10 调色

调色写成三层比例＋真实色名，比例读起来在各类生成端都稳定：

    60% warm ochre, 30% deep charcoal, 10% rust-red

三条规则：

1. **比例必须从创作者指示、场景内容或已接受参考推导**，不准凭空发明一套盖过去
   （`IMG-13`）。推不出来时保持未决，写清缺什么，不要用"电影感配色"填。
2. **写真实色名**，不写"高级灰""莫兰迪"这类检索标签——它们在不同生成端指向完全
   不同的颜色。
3. **允许逐场变化的项要另写**：冷暖偏移、对比、留白、光比。不写清楚哪些可变，
   下游要么全片一个调子，要么每场自由发挥。

绘制类形态把这一层改写成本形态能执行的东西：上色分区数、阴影边缘硬度、
描边规则、材质响应规则。比例逻辑保留，载体换掉。

## 3. 技术性的光，不是含糊的氛围

    ✓ single overhead key light, soft 2:1 ratio, smooth falloff
    ✗ dramatic cinematic lighting

每一条图片 prompt 的光至少回答：**主光源在哪、什么方向、亮暗比、衰减是硬还是软**。
需要时再加：背景亮度、允许的高光、曝光优先给谁。

- **参考板与设定图**：需要可比较性时，均匀、方向明确的光通常优于戏剧光——这是
  **用途相关的默认**，不是硬规则。为了好看把人物板打成侧逆光，代价是下一次比对
  两个版本时分不清是造型变了还是光变了。
- **场景板**：光向要与地理一致。同一地点同一时段的多个 View 共享主光源、色温关系与
  对比方向（`IMG-10`），朝向造成的逆光差异不需要拉平，但要写得出它是朝向造成的。
- **逆光戏**：整帧曝光给背光而不是给脸，脸可以掉进阴影，剪影与轮廓承担画面。

## 4. 材质：名字＋表面处理

材质写成**材料＋表面状态**，不写"质感很好"：

    ✓ board-formed concrete / oxidized copper verdigris / brushed steel with fingerprint smear
    ✗ high-quality material, exquisite texture

材质承担两件事：识别（同一个地点靠同一组材料被认出来）与光的行为（哑光吸光、
金属产生窄高光、湿面产生镜面反射）。写材质其实是在写光怎么落在上面。

## 5. 视觉暂存器：一行，不叠词

暂存器是整条 prompt 的"底子"，**择一，不要两种都写**：

| 暂存器 | 写什么 | 什么时候用 |
|---|---|---|
| 有机胶片感 | 有机颗粒、去饱和、柔和衰减、film still 的整体感 | 需要年代感、纪实感、暗部有颗粒 |
| 干净数字感 | 干净现代数字、细节锐利、极细颗粒、自然肤色、中等对比 | 需要通透、当代、皮肤真实 |
| 绘制形态改写 | 线条粗细规则、上色分区数、阴影边缘硬度、材质响应规则 | 二维、水墨、Q 版等非摄影形态 |

**本身就自带颗粒与质感的生成端不要再叠词**：一行暂存器足够锚住方向，多写只会挤掉
真正的锚点。若创作者的档案声明了具体的机身、镜头或胶片词汇，逐字沿用该档案的写法，
本套件不自造器材名，也不把器材参数当成主要控制手段。

## 6. 注意力预算与写法硬规则

1. **自然流畅的散文，不是关键字堆叠。** "4k, masterpiece, trending" 不产生作用。
   生成 prompt 不要 ALL-CAPS 段标；CAPS 区块（CHANGE／PRESERVE EXACTLY）只用在编辑
   车道（见 [edit-and-revision.md](edit-and-revision.md)）。
2. **不要把 prompt 撑大。** 精确胜过冗长：过了某个点，每多一句都在稀释注意力，
   细节开始掉。删填充词，留锚点。这是 `craft_default` 的注意力预算，
   **不得用字数或长度阻断交付**；审查者指出的是"哪个锚点被稀释了"，不是"超了多少字"。
3. **正向优先。** 要干净皮肤写 clean dry skin，不写 no acne；要空街写 empty deserted
   street，不写 no people。`not cartoon, not anime…` 这种 NOT 堆叠会把那些概念注入画面。
   两个例外：项目确实没有可读文字义务时的一句无文字要求；以及编辑车道的
   CHANGE／PRESERVE 结构，那里明确移除是合法操作，但必须配上填补
   （"移除路灯" ＋ "其后是连续的砖墙"）。
4. **画幅、分辨率、模型名、seed 是平台参数**，在生成界面里设，不写进正文。构图措辞
   （竖幅全身取景、宽幅全景取景）可以写。
5. **rule of thirds 是本套件的常规做法**，加在图片与视频 prompt 上——**角色设定图除外**
   （设定图要的是可比较的居中构图）。
6. **文字与刺青要具体。** 画面文字给逐字内容＋字体／字重／颜色；刺青给具体图案＋
   clean line-work。含糊的"加点字""有纹身"一定会糊掉。文字政策的两层映射见
   [common-recipe.md](common-recipe.md)。
7. **不写真人姓名、不写品牌与 IP。** 把参照翻译成特征：脸、体格、气质、年代。

## 7. 写实漂移与插画触发词

照片写实的项目里，几个词会稳定地把结果拉向概念美术：

    避开：character reference sheet、painterly、concept art
    改用：studio photographs、film character sheet、cinematic film still

飘掉时的修法是**加强写实锚点**（真实材质、光的技术描述、暂存器一行），
**不是加 NOT 堆叠**——那会把插画概念再注入一次。

反向也成立：刻意要绘制感的项目，不要用摄影暂存器打底再"加一句风格前缀"。前缀改变的
只是检索标签；形态改变的是**哪些字段必须展开、哪些可以塌缩**。

## 8. 失败征兆与检查

### 失败征兆

- 调色只有"氛围感""高级灰"，没有比例也没有真实色名；
- 光写成"电影感光线"，没有主光源、方向或亮暗比；
- 材质只有质量词，没有材料名与表面状态；
- 两种暂存器同时写，或在自带质感的生成端反复叠颗粒词；
- 写实项目里出现 painterly／character reference sheet；
- 正文里出现画幅、分辨率、模型名或参数语法；
- 负向堆叠代替了正向描述。

### 检查

1. **结构**：平台参数不在正文；`readable` 与全局无文字要求不并存；
   角色设定图没有 rule of thirds。
2. **内容**：调色比例与色名指得回来源；光的四问有答案；材质有名字与表面处理。
3. **默认**：注意力预算、暂存器选择与审美语言是 `craft_default` 与 `taste_option`，
   记录创作者选择后在重新导出文本时保持一致，不单独阻断交付。
