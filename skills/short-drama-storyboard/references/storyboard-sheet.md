# 场次故事板 previs sheet

## 这一层解决什么（`SHT-21`）

`storyboard_sheet` 是 `shots.jsonl` 和 `keyframes.jsonl` 之间的**可视化 previs 层**：把一组镜头
画进一张多格故事板纸，每格是一个镜头的 start beat 的**粗略草图**，配颜色标注承载调度、机位、
动作、光向与 VFX 意图。整场观看节奏、走位、摄影一次摊在一张纸上，花钱渲染前先比较、修正。

它是 [场次视觉计划](scene-visual-plan.md) 的**可视化对应物**：scene-visual-plan 写文字策略，
sheet 把同一策略画成可读多格 previs（可用 `scene_visual_plan_ref` 投影已接受的文字计划）。

**分组**：一张 sheet 覆盖一个连续叙事节拍组（如「A 组：屠村之夜，开篇→潜伏撤离，覆盖第一章
前半段」），不强求恰好一个场景；镜头多于格上限就拆多张，按叙事先后编 `A/B/C…` 组。

## 它拥有什么 / 不拥有什么

- **拥有**：previs 构图草图、机位与动作箭头意图、VFX/能量强调、光向、格↔镜头映射、组与格顺序。全是 previs 意图，不是最终画面。
- **不拥有**：镜头 purpose/duration/边界（归 `shots.jsonl`）、身份与地理事实（归资产）、最终画风（下游 keyframe/video 阶段才进）、任何故事事实。sheet 与来源冲突时退回 owner。

## 语言与可复制格式

- **提示词正文跟随 `short-drama.json#/format/prompt_language`（默认 `en`）**，与同阶段
  [keyframe 提示词](keyframe-craft.md) 同一个值；节标题、格↔镜头、视觉计划等元信息跟随
  `#/language`。两个值都由 core `project_tool.py` 的 `status` 报出，不要各自猜默认值，
  也不要一份文件中文、另一份英文。
- **负面清单与颜色图例一律用正文语言写完**，不要中英混排（本文档的中文清单是给技能读的
  规则，不是可以直接抄进英文 prompt 的字面串）。
- **正文放围栏（```` ```text ````），不放 `>` 引用块**：sheet 正文有几十行，引用块复制出来
  会带 `> ` 前缀，失去「可复制」的意义。keyframe 那种单段短正文才用引用块。
- **派生文本由 [render_sheet_prompts.py](../scripts/render_sheet_prompts.py) 渲染，不手写。**
  本文档只保留需要判断的部分（分组、量化关系、锚点选择、连贯性）；纯机械的版式规则
  ——围栏、占位省略、标注行、负面清单、锚点位置——由脚本执行，避免同一份记录两次渲染
  得出不同版式。脚本不翻译：语言不一致时它拒绝渲染而不是猜。

## 版式契约（网格 + 页眉 + 格标题）

生图模型对版式很敏感，**把网格写死**才不乱排：

- **参考图绑定写在正文第一段**：用一句自然语言把名字绑到参考图
  （`使用提供的参考图像作为角色与场景依据：乔万尼=@[...]、教室=@[...]`），下文一律用名字引用，
  不再重复 @tag（见「角色视觉锚点」）。**不要用 `[参考图]`、`[页眉]` 这类方括号标记块**——
  它不是自然语言，生图模型不认这种伪语法，只会把括号当画面内容或直接忽略整段。
- **网格**：写明 `列×行`、实际填几格、空格留空表示空缺、填充顺序（左→右、上→下）。
  例：`4列×2行，仅填 7 格，第 8 格留空；A1→A7 依次填`。
- **格比例统一**：每格严格同一横纵比、尺寸统一、**无混合比例**；panel 取景比例=项目交付比例
  （竖屏剧集 9:16；横版项目 16:9）。纸面整体比例按格数网格排布另选，与单格取景是两回事。
- **格标题格式**固定：`SHOT-<id> / 景别 / 动作节点名`，一个动作节点对应一格。
- **页眉区**：适配画风的排版 + 细分割线 + 层级；图形元素置于分镜格之外。只放约定的标题
  文字（如两行引号标题），**不得添加其他页眉文本**。

## 格↔镜头映射（`SHT-21 · reviewed_invariant`）

- 每格 `shot_ref` 指向 `shots.jsonl` 一个准确镜头；一镜只出现一格，一格只映一镜。
- 格顺序 = 镜头场内/叙事先后；previs 不重排上游已定事件先后。
- 每格只投影该镜头 **start beat**（与 [keyframe start-only 纪律](keyframe-craft.md) 一致）：可画
  「已在运动中」的动态起点，但不得画进本镜随后才发生的认出、松手、决定或持物变化。

## 每格怎么写（`SHT-27`）

**每格独有的东西写足，全张共用的东西提到全局写一次。** 这是 sheet 可读性的分界线：量化构图
是每格独有的、抽掉就塌；颜色图例、摄影词表、负面清单、灰度锚点是全张共用的，逐格复述只会
把 60 行的纸变成 500 行的字段转储。

每格一个标题行 + 一段正文 + 一行标注：

- **标题行**：`PANEL <序号> — <景别，含机位角度> / <运镜起点→终点，或固定机位>`。
- **正文**（一段连贯散文，不要字段名冒号列表）：依次写
  ① 一个定格瞬间的角色位置与**量化关系**（占比/倍数/角度）、疏离/对峙/焦点关系；
  ② 暗示运动的细节（灰尘悬浮、布料抖动、手指颤抖用虚线）——仍是**一个定格瞬间**，
  不是先后动作序列；③ 最小必要环境物；④ 石墨排线团块表现的光晕/红晕/反光。
- **标注行**：`标注：` 后**只列本格真实存在的箭头**（如 `红-手臂下压；蓝-慢推向老师；绿-三段式构图`）。

两条硬纪律：

- **不适用的内容整句省略，不写占位**。写「特效/元素：无」「动态元素：无（纯反应定格）」
  「红色箭头-无（老师尚静止）」是噪音：模型会把「无」当成要画的内容，人也读不下去。
  没有特效就不提特效，固定机位就不写运镜。
- **标注行不复述末尾的颜色图例**。红/蓝/绿/橙/黄 各代表什么在全局段写一次；每格重抄一遍
  五色图例，29 格就是复述 29 次，其中大半是「-无」「-固定」。

**从情绪/动作高点开始**：第一格直接进最高张力，不用空镜、平静或缓慢介绍开场。

**格后总控（全局段，每张 sheet 写一次）**：元素进展（早/中/晚期光效递进）、摄影词表（本组机位
词汇）、环境最小化（少量氛围元素、不拥挤）、颜色标注系统、全局负面清单。负面清单写成短句，
不要堆成一行逗号串。

## 角色视觉锚点（画在 sheet 上，`SHT-23`，可选）

多角色或黑白易糊时用；简单 2–3 人情绪场可只靠第一段参考图绑定 + 每格提到名字。
需要时**把每个出场角色的固定剪影锚点摊在 prompt 里**，逐格复用。

**位置与范围**：锚点是身份锁，写在**参考图绑定与黑白画风段之后、开场纪律之前**——模型要先知道
「谁长什么样」才能读懂后面每一格。不要掉到负面清单后面当尾巴。范围**只列本张 sheet 真正出场的
角色**；把全集角色表逐张重抄，等于让模型去画没出场的人。

- **灰度色调当身份通道**（黑白介质专用）：给每个角色分配一档固定灰度并全 sheet 一致——
  例：主角=最浅/以留白为主，反派巨汉=最深/密集排线，配角=中灰/中等排线。黑白里认不了颜色，
  就靠**色调 + 剪影**区分身份。
- **固定剪影特征**：体型、头部轮廓形状、发型/头饰凸起、服装轮廓、疤痕、持物——挑少量稳定、
  互不重复的，逐格保持。
- **参考图在正文第一段统一绑定一次**：用一句自然语言把名字绑到参考图——
  `使用提供的参考图像作为角色与场景依据：乔万尼=@[乔万尼角色设定板.png]、老师=@[老师设定板.png]`；
  **下面的锚点、面板正文、速写一律只用名字「乔万尼」引用，不重复 @tag**。绑定一次、逐处用名，
  改参考图只动这一句，也避免每格重复 @tag 让模型反复解析。结构上进各角色 `reference_refs`。
- **屏幕方向约定**：写死每个角色的惯常朝向/移动方向（如「主角通常左→右，反派在右侧面朝左
  攻击」），锁 180° 轴线。

锚点只约束「怎么认出同一个人」，不改身份事实本身（那归资产）。

## 连贯性纪律（`SHT-24`）

- **同一主体不复制**：被攻击、倒地、被标记的角色始终是同一主体，绝非额外复制/重影形象。
- **一格一定格瞬间**：每个角色仅呈现一种姿态/状态，格内不含表示「之前/之后」的文字或对比图。
- **严格数量**：涉及计数的画面严格展示对应角色数量，不多不少。
- **空间一致**：柴房、燃烧村落、村口、后山方向等场景元素跨格保持同一空间关系。
- **屏幕方向一致**：沿用角色锚点里的朝向/移动方向，切格不翻轴。
- **景别↔压迫感语义**：大远景=环境压迫，中景=对抗张力，近景=情绪压力，特写=极限生存本能；
  景别服务这层压力变化，不是均匀切分。

## 画风：粗略 previs + 彩色标注（`SHT-22`）

画面本体是**黑白规划稿**，和项目最终画风脱钩；标注用彩色叠加（黑白画 + 彩色箭头模型）：

- 画面本体仅黑白：粗铅笔线条、最小细节、快速手势草图能量、强剪影、环境细节低；亮部留白、
  暗部石墨排线（hatching）、高对比、粗纹纸质感。**不上最终画风的材质光词**（水彩/赛璐璐留给
  keyframe 阶段）。特效以石墨排线团块表现：拖尾、接触爆发、尘埃环、冲击波环、火焰/烟雾团块。
- **颜色标注系统**（叠加在格上，供人与下游 video 读）：

| 颜色 | 标注 |
|---|---|
| 红色箭头 | 身体/主体运动方向 |
| 蓝色箭头 | 摄影机运动 |
| 绿色标记 | 构图/组成笔记 |
| 橙色标记 | 光向 |
| 黄色标记 | VFX / 能量效果（按需，普通场次可省） |
| 黑色文字 | 简短镜头笔记与面板标签（如 `SHOT-03`） |

标注只记意图，不改上游：机位/景别仍以 `shots.jsonl` 为准，箭头是它的可视化。

## 量化空间关系（prompt 不可精简，`SHT-25`）

每格描述用**可量化的关系**锁住构图，不写空泛「很大/激烈」：肩宽约为对方 1.8 倍、冲击波环
直径约为头部两倍、瞳孔约为眼眶三分之一、刀身与地面约 30°、门缝占画面中心约 40%……
这些数量关系正是模型认出构图的依据，**逐格写足、不得精简**。

## sheet 下方：GEO 俯视图 + 人物速写条（可选强化，`SHT-26`）

复杂空间或多角色场次，在分镜格下方加两栏，把**空间锁 + 身份锁**画进同一张纸：

- **左栏 场景俯视图**：铅笔线俯瞰示意，标点位与关系（如「村口土地庙 / 村正家(已起火) /
  柴房(初始位置) / 后山小径入口」）+ 进攻/移动方向箭头。等同 GEO 空间锁。
- **右栏 人物速写条**：横排每角色一个近方形速写框，铅笔勾典型姿态 + 剪影 + 典型道具 +
  框下标签 + `@参考图`。等同把角色参考条钉在 sheet 上。

普通短场次省略这一区，只出分镜格。

## 排除（storyboard 专用负面清单）

写进 prompt 时按正文语言译成**短句**（`无时间戳。无对白文字。无演唱。`），全局段写一次；
不要把这几条压成一行中英混排的逗号串。

- 格内除颜色标注外，不含正文文字、标签、图标、注释；
- 无时间戳、无对白文字、无演唱、无水印/logo；
- 无最终画风上色/成品级插画/密集细节/分镜格底色；
- 无重复或重影形象、无「前后对比」复制图、无道具/图标/悬浮物式的特效标记；
- 不出现镜头资产绑定之外的额外人物或敌人。

## 下游：每格 → 一张干净首帧

sheet 接受后，**每格投影成 `keyframes.jsonl` 里对应镜头的一张干净最终首帧**（首帧法保留，
配方见 [keyframe-craft.md](keyframe-craft.md)）：keyframe 起首写项目已接受画风的风格锁、绑定
资产、把本格 previs 构图/机位/动作当 blocking 参考落成正式画面。

**video 阶段的首帧一律取 keyframe，不取粗草图 sheet。** 唯一的例外是 storyboard-driven 容器的
**动作顺序参考**（`role=action_sequence`）：项目预算不足时可以直接拿 sheet 当那一条参考，保真较低
但机制相同（见 video 阶段的交付档案第七节）。这是「参考什么动作顺序」，不是「从哪一帧开始生成」——
首帧永远是已接受的 keyframe。

## 失败征兆

- 格里出现镜头 `end_boundary` 才有的事实（认出、松手、到位）——start-only 漂移；
- 角色在格间糊成一团或串脸——没摊灰度色调 + 剪影锚点；
- 网格乱排、格比例不一、格标题缺失——版式契约没写死；
- 一格画了两镜或一镜拆两格，格数与镜头对不上；
- 标注箭头改写了 `shots.jsonl` 机位，而不是可视化它；
- 画面上了最终画风材质，越权占了 keyframe 的活；
- 描述用「很大/激烈」代替量化关系，模型认不出构图；
- 正文语言跟 keyframe 提示词不一致（一边中文一边英文）——没跟 `#/format/prompt_language`；
- 满屏「无」「固定」「不适用」占位，或每格重抄五色图例——该省略的没省、该提到全局的没提；
- 灰度锚点掉在负面清单之后，或逐张重抄全集角色表；
- 正文包在 `>` 引用块里，复制出来每行带 `> ` 前缀。
